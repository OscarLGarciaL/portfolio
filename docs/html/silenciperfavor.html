Silenci Per Favor —animated video

description

The Youth Center of Sagunt required an animated spot to play before film screenings, reminding attendees to silence their phones and maintain a quiet environment. The animation features characters inspired by everyday objects found in a cinema, using humor to create an engaging and universally understandable message for all audiences.
